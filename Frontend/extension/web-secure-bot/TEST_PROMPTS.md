# 🧪 Test Prompts for Web Security Bot

## 🔒 Security Analysis Questions
- "Is this website secure? Look for any suspicious elements."
- "Are there any forms on this page that could be phishing attempts?"
- "Check if this website has any suspicious or malicious links."
- "Does this website look legitimate or like a scam?"
- "What security concerns should I have about this website?"

## 📊 Content Analysis Questions
- "Summarize what this website is about in 2-3 sentences."
- "What is the main purpose of this website?"
- "Are there any red flags in the content or design?"
- "What type of website is this (e.g., e-commerce, news, social media)?"

## 🔍 Technical Analysis Questions
- "What forms and input fields are on this page?"
- "How many external links does this website have?"
- "What is the title and URL of this page?"
- "Are there any JavaScript errors or suspicious code?"

## 🚨 Phishing Detection Examples
- "Is this a legitimate bank website or a phishing attempt?"
- "Does this login form look suspicious?"
- "Are there any urgent messages or threats on this page?"
- "Does this website ask for sensitive information inappropriately?"

## 💡 General Questions
- "What should I be careful about on this website?"
- "Is this website trustworthy?"
- "What are the main features of this website?"
- "Are there any obvious scams or fraud attempts here?"

---

## 🎯 Quick Test Workflow
1. Go to any website
2. Click the extension icon
3. Copy-paste any question from above
4. See how Gemini analyzes the page!

## ⚡ Pro Tips
- Test on both legitimate and suspicious-looking websites
- Try asking the same question on different sites
- Compare responses to see how the AI detects patterns
- Use specific questions for better, more focused responses
